1). PROJECT DESCRIPTION

Gestion sistem, is a software application developed in Python for managing customers, services, and reservations.

The system was designed using Object-Oriented Programming (OOP) principles. It implements abstract classes, inheritance, polymorphism, encapsulation, data validation, and advanced exception handling.

The main purpose of this project is to demonstrate the practical application of programming concepts through a system that simulates business operations, customer registration, service management, reservation processing, and cancellation.
